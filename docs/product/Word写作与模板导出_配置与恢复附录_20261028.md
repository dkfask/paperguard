# PaperGuard 写作与模板导出配置与恢复附录

日期：2026-10-28。本文保存[需求模型](./Word写作与模板导出需求模型_20261028.md)引用的配置和异常细则；主文档定义范围、门禁与状态，本文不代表实现或运行验收通过。R/P/§ 编号除本节标题外均指主文档。

## 1. 参考文献配置

教师设置默认配置与学生切换权限。首批目标配置为：GB/T 7714-2025 和 2015 兼容版各含“顺序编码制”“著者—出版年制”，另有 APA 7 与 IEEE。选择项须展示版本/制度、类型覆盖、规则来源和学校扩展，不能只写“GB/T”。

| 配置 | 文末排序 | 显示标注 |
| --- | --- | --- |
| GB/T 7714-2025 / 2015：顺序编码制 | 已引用条目按首次引用顺序；无引用/未引用条目按下方学校扩展处理 | 连续顺序编号，与稳定条目 ID 分离 |
| GB/T 7714-2025 / 2015：著者—出版年制 | 无论有无引用，按所选版本规定的文种分组、作者字顺/中文排序键、出版年及同作者同年消歧规则 | 著者—年份；不强加顺序编号 |
| APA 7 | 无论有无引用，按作者字顺；同作者按相应年代/题名及消歧规则，缺作者按标准替代规则 | 著者—年份；文献表不加顺序编号 |
| IEEE | 已引用条目按首次引用顺序；无引用/未引用条目的产品顺序见学校扩展 | 方括号顺序编号 |

**学校扩展（用户已确认）**：正文引用可选。对顺序编码配置，有引用时将未引用条目按粘贴顺序接在已引用条目后；完全无引用时保留粘贴顺序。作者—年份配置始终按标准排序，不适用保留粘贴顺序。不得丢弃未引用文献。原始粘贴顺序作为稳定输入保存，不受显示重排影响。

配置须列明正文引用可选及学校版式扩展。APA 文献表的引用对应要求不被产品扩展替代；IEEE 允许未引用文献，但本产品自定追加顺序不冒称标准原文（S-03/S-04）。

切换版本/制度复用事实元数据，由系统重排文献、更新编号/著者年份和已插入引用，并提示变化。中文姓名排序键、团体作者、无作者、同作者同年、混合文种及类型规则须在配置中按权威条款固定；规则不完整的配置不能发布，不能靠教师逐篇排序。

2015 版仅供学校旧模板兼容，官方版本状态见[本附录 §6 的 S-01/S-02](#6-官方来源与核对范围)。状态记录不证明条款实现；配置发布前须完成条款及边界示例映射。
依据：D 按标准/制度排序及学校扩展裁决；E1 [本附录 §6](#6-官方来源与核对范围)。

1101 的著录标点和页码按所选标准；字体、段落及悬挂缩进按学校规则。旧批注中的标点/专著页码表述不静默覆盖标准，新增覆盖须有明确学校扩展。

**语种事实**：每条文献保存 `language`/文种（可多值及未知）、原文依据、来源、系统建议与确认人/时间/状态。系统可建议，学生确认或修正；英文题名不等于英文文献，不能把未知、混合或建议值当作已确认英文。GB/T 著者—出版年制需要文种分组时，缺少已确认排序事实阻断该配置正式导出；规则须说明混合文种归组。其他配置不依赖文种时，缺失仅使内容统计不完整，不阻断格式交付。

**T-08 统计**：毕业年度 Y 直接派生自封面语义为“答辩日期”的事实字段年份，按 Y−2～Y（含边界）统计窗口内至少15篇、其中英文至少5篇，早期文献保留。不另建可漂移年度，不用提交日期或当前年份替代；日期变更自动重算。显示总数、已确认窗口内数、窗口内已确认英文数、未知年份数、窗口内未知/混合或待确认语种数，及“统计不完整”的具体原因；只能按已确认下界说明已满足，未知可能改变结果时不得报不达标或达标。缺答辩日期/年份有歧义时显示“窗口待确定”，不展示伪精确计数。数量、时效和英文篇数提示不阻断导出/提交，M2 可作为教师审核依据；排序必需事实仍按 R-13 门禁。

## 2. 异常与恢复

| 场景 | 分类、状态与可执行下一步 |
| --- | --- |
| 损坏包、未知 OOXML 部件/元素/属性/关系、替代分支未覆盖 | 模板上传时不通过准入；学生输入时先阻断当前项目交付，按 §6.1 判定是否属于已承诺能力缺口；列部件/路径并提供源文件恢复或适配进展 |
| 规则冲突/无来源 | 待规则确认；教师查看来源和影响并澄清，再重新准入 |
| 映射失败、已声明支持能力失效、识别无法绑定 | 未发布版本进入能力适配；已发布版本按 §6.1 的影响范围暂停交付，不能把运行状态回写成模板草稿；系统团队处理并复验 |
| 封面缺项、文献必需事实缺失 | 内容待补；显示字段与入口，允许草稿，补齐后复检 |
| 文献为空 | 按模板是否必需判定；不以“正文无引用”报错 |
| 文献引用失效、图表公式章节引用悬空或纯文字待绑定 | 指出来源和候选目标，批量推荐确认；可为误报建立有效局部非引用标记，其余未解决项阻断，按 R-11/R-19 复检 |
| 复杂粘贴/公式转换失败 | 待补录；保留原始载荷，提供原文恢复与对应编辑器/源文件导入；未解决对象仍被保留在论文中则阻断 |
| 位图不满足适用规则或缺必检证据 | 说明规则来源、对象和属性；换图、导入可信源，内容对照确需时补录文字；重建仅按 R-09 限定对象并预览确认；识别故障转系统处理 |

| Word 不可用、缺字体、弹窗、超时、识别服务故障 | 运行失败；保留快照，自动报障并提供重试/进度；失败产物不开放下载 |
| 报告为空、文件/布局被替换、摘要过期 | 凭据失效；从冻结快照重新生成和检查；不能复用旧结果 |
| 已提交/接受/归档成品因完整性问题被撤销资格 | 按主文档 §6.4 标记、通知并暂停受影响操作；误撤销经同摘要原件独立复核恢复原资格，无须重开；真实缺陷由教师决定修订并建立替代关系，历史保留 |
| 直接 API、旧下载链接、force | 同样执行权限和 P-03/P-04，返回具体拒绝原因 |
| 归档失败 | 已接受/归档失败；保留教师决定，幂等重试同一提交成品并告警，禁止假报已归档 |
| 迁移失败、撤回与审核并发、重开与归档并发 | 保留原事实；返回服务端已生效状态和下一步；不覆盖旧版或把旧归档绑定到新版 |

## 3. 视觉对象与恢复细则

图表题注绑定对象 ID，按模板中的章节/附录和出现顺序编号；增删移动后同步题注及交叉引用。图例与图题分别建模；原生图表的数据、坐标轴、标签和图例须有对象映射。

学校格式约束仅由模板中有来源且适用的规则触发（R-03）；没有依据时不能给全部截图加字体、字号、分辨率或逐字对照要求。内容完整性及已声明的工程质量检查另行标识，工程阈值按 §10.2 管理，不冒称学校规范。

- 可编辑文本框、图例、图表文字：检查文本内容、有效字体/字号及样式；解析属性与最终布局证据共同支持结论。
- 位图：按适用规则检查输出尺寸、缩放比例、裁切、有效分辨率、文字区域、可读性及有可靠对照的文字内容。有效分辨率按像素数除以输出英寸计算；不能把图片像素高度直接宣称为字体点值。
- 字体/字号：仅在取得可编辑源或能关联到原文字对象的可信字体证据时判定；OCR 猜测与高置信度本身不构成该证据。
- 识别记录绑定对象 ID、源摘要、区域/页面位置、文字、置信度、对照来源、检查项及识别配置。内容一致性必检时须有源文本或补录事实文本作对照；单次 OCR 输出不能同时充当自身真值。
- 识别须通过冻结标注集、分组准确性/漏检/误通过及来源覆盖指标；计算口径、分母和失败样本处理见[白名单附录 §6](./Word模板准入白名单与覆盖附录_20261028.md#6-视觉指标与计量)。缺阈值或证据不能判为通过。

证据不足时定位对象并说明所缺证据，提供换图、源文件或受控重建入口。可重建资格须同时满足：教师在模板中限定类别，学生声明用途，系统按类别规则和来源检查通过。**仅限简单文字示意图；数据图、实验截图、测量结果等证据性图片禁止重建**。疑似证据图、用途与来源冲突或无法判定时禁止重建，保留原件并走源文件/替换恢复；学生单方面改标签不能获得资格，教师也不能豁免硬限制。记录模板类别版本、声明、系统判定及理由、源摘要和操作人；重建保留原件及差异预览，学生确认事实后另建对象。内容对照确需时补录图中文字，OCR 不作自身真值。系统故障按 R-23 处理。
依据：D 可验证位图边界；E1 R-03、P-01/P-05。

以上是平台能力合同。1101 当前没有图内统一字体/字号或逐字对照要求，且本次试点明确不启用 OCR、重建或外部识别；不能将平台级恢复入口误呈现为本试点已开放能力。后续规则/能力变更须另版准入。

## 5. WPS 兼容检查

WPS 兼容检查由系统团队执行，固定操作系统、WPS 版本/构建号、字体、样本/预期及文件摘要。须正常打开，无修复警告/崩溃，文本、对象及引用完整。分页不同不阻断 Word 基准交付；声明兼容环境出现丢内容/损坏等完整性失败时，阻断对应范围的正式交付及发布/更新，复验后恢复。WPS 不代替 Word 验收；版本未冻结不得声明已支持。
