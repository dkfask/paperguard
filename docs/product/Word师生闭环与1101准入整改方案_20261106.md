## 1. 目标

完成以下主路径，并让每个结果都能绑定到明确的源代码、模板、规则、成品和运行环境：

**教师配置并发布 1101 试点 → 学生在系统内完成写作、检查和 Word 导出 → 学生提交冻结版本 → 教师在系统内批注并退回 → 学生修订重提 → 教师接受 → 后台自动生成并校验 Word 归档。**

PDF 是可选附加格式，不是写作、提交、审核或归档前置。整篇 DOCX 导入是可选迁移入口，不替代系统内写作主流程。图表与章节交叉引用按已确认的 M1 范围补充暂缓；本方案不扩大该范围。

## 3. 验收原则

### 3.1 大于 90% 的计算口径

建议以冻结模板和规则版本中的“适用规则 × 实际适用对象”作为计分单元，逐项结果为通过、不通过或不可验证。默认等权，公式为：

```text
整体准确率 = 通过的适用检查单元数 / 全部适用检查单元数 × 100%
```

仅当结果严格 **大于 90%** 且所有硬阻断项均通过时，普通格式项才可判为整体通过。失败和不可验证均计入分母且不计入通过；只有规则证据证明不适用时，才可从分母排除。不得在看到结果后临时删除失败项、调整权重或改写适用范围。

90% 只用于容纳模板准入时已经识别、可容忍的非关键格式偏差，不用于掩盖以下硬阻断：

- 文件损坏、来源/模板/规则/成品摘要不匹配或证据绑定失败。
- 内容、段落、表格、图片、标题层级或固定模板结构静默丢失、错配或被未授权改写。
- 必需事实字段缺失，或提交候选版本与教师审核对象、归档 Word 不是同一冻结版本。
- 适用的关键 Word 分页证据缺失、过期或来自其他模板/成品；依赖分页的检查不能用仅解析 DOCX 的结果冒充通过。
- 未识别 OOXML/媒体对象导致内容或版面影响无法判定；绕过权限、跨学生读取、未经授权下载。
- 文献必需事实、编号/题注绑定或格式规则出现会改变成品含义的错配。

每份报告至少展示总分、分子/分母、各规则得分、失败项、不可验证项、被排除项及其依据、硬阻断状态。实现前须将 1101 规则映射为“硬阻断”或“可计分格式项”，不能由渲染器临时决定。

### 3.2 系统责任与 PDF 边界

- 系统负责生成和验证格式；不得以教师逐篇勾选格式正确、学生自检或“带提示放行”替代自动门禁。
- 教师审核聚焦论文内容和教学反馈。任何 Office 人工核查项不得成为绕过未实现格式检查的放行凭据。
- PDF 可按请求生成。PDF 缺失或生成失败不能阻断满足 Word 门禁的交付；内部是否用 PDF 采集版面证据，必须与同一 Word 成品绑定且不得将其变成学生必交件。

## 4. 分阶段整改

阶段顺序是实施门禁，不改变产品中的 M1/M2 命名或已确认范围。每阶段未达到退出条件时，不进入依赖阶段。

### 阶段 A：冻结代码与验收基线

1. 对当前 45 项工作区差异逐项归属到本任务，区分实现、测试、文档和临时产物；保护已有改动，不覆盖或清理无关内容。
2. 明确进入验证的文件集合并形成可复现源码快照。任何本地测试、E2E、CI 和浏览器报告都记录完整 SHA、工作区是否干净、命令、配置和结果。
3. 将第 3.1 节的 90%公式、硬阻断清单及 1101 每条规则的分类纳入版本化验收配置；固定结果状态和报告格式。
4. 按仓库 README/AGENTS 规定运行相关门禁，不以旧 HEAD 上的绿色测试替代当前快照验证。

**退出条件：**代码快照可复现；90%计分规则、硬阻断项和 1101 适用检查单元均有版本化定义；未运行的门禁明确列为未验证。

### 阶段 B：正式准入 1101 模板

1. 通过 `POST /api/templates/parse` 正式上传 1101 文件，使候选模板绑定源 DOCX、`source_asset` 和 SHA-256；不使用缺少源资产的低层解析调用作为产品上传结论。
2. 核对候选模板摘要与实际上传文件一致，并对完整 OOXML 包、关系、媒体、分节、兼容分支和文本框执行独立盘点。未知结构默认阻断，不能被高层解析器静默滤除。
3. 对账规则清单和目录/正文结构：
   - 确认 `2.4 物联网安全技术`、`3.3 物联网系统数据分析`、“附录”分别是应补映射的真实章节，还是样例目录项；每项保留来源、决定和证据。
   - 实现并验证 T-05 数字字体、T-06 关键词标签、T-08 内容质量提示、T-09 文献标准与版式优先级、T-10 不启用 OCR 的图片边界、T-12 标题层级与目录重建，以及说明框/批注排除映射。
   - T-08 数量、年份和语种指标按已裁决口径只提示/供教师内容审核，不纳入格式分数硬门禁。
4. 逐条校验模板允许的章节、封面字段、标题层级、图片和普通表格映射；目录只保留与实际结构匹配的条目，最终由系统重新生成。
5. 使用普通稿、长内容稿、混排数字、跨页表格、图题/表题、二级/三级标题和分页边界构成的有限组合样本试排。一个简单样稿通过不能替代能力覆盖。
6. 生成不可变准入记录，绑定源文件摘要、规则/检查器版本、白名单版本、样本输入摘要、预期结果、版面环境和报告摘要。

**退出条件：**所有实际模板结构已盘点；必需能力映射完整；未知/未绑定项为零；样本组合和负例符合准入契约；1101 候选可进入下一阶段。任何目录错项、来源绑定缺失或不可验证结构仍未解决时不得发布模板。

### 阶段 C：完成 Word 原生版面验证

1. 先修复本地试排环境：提供受控来源的 LibreOffice bridge JAR，并按仓库固定 SHA-256 校验；不得关闭摘要校验。用容器路径或明确配置路径，不把默认路径不存在误报为产品格式失败。
2. 对 1101 实际生成的成品在固定 Word 环境重新分页；记录 Word 版本、操作系统、字体、模板版本、检查器版本、成品 SHA-256 和布局证据 SHA-256。
3. 核对封面字段、摘要/目录页码、一级至三级标题、标题后的正文样式继承、数字字体、图表/图题居中、表格边框/字体/跨页、页眉页脚、分节和总页数。对发生分页变化的成品重新执行最终检查，证据绑定最终输出摘要。
4. 自动检查消费与成品摘要相同的 Word 布局证据；Word 忙、超时、字体缺失或证据失效均标记不可验证并阻断相关正式交付，不交给教师人工确认代替。
5. PDF 若作为可选下载，单独检查同源绑定；不将 PDF 检查失败写成 Word 失败。
6. 单独确认未来生产 Word 节点的操作系统、Word 版本、授权、运行隔离、队列、超时和故障恢复方案。Mac 本机验证不等于服务器节点已可用；未确定生产节点前，不宣称生产 Word 分页链已完成。

**退出条件：**1101 所有分页类适用检查均由固定 Word 实排和对应布局证据验证；重新分页后的最终 DOCX 检查通过 90%门槛且无硬阻断；正常稿可交付、关键负例被拦截。生产排版节点信息另列为部署前置。

### 阶段 D：对齐浏览器师生闭环

1. 更新或新建主流程 Playwright 场景，使用 1101 已准入模板及合成数据。主链由学生在系统内创建/编辑正文、封面、图片/表格并执行检查；不上传 4.7 整篇 DOCX。整篇导入留作独立可选迁移测试。
2. 以系统管理员准备测试批次、阶段和指导关系；教师发布要求；学生完成模板要求、导出 Word 并提交。
3. 教师在网页打开冻结提交、对内容块批注并退回；学生按反馈修改并重提；测试确认第一次提交及其检查凭据保持不变。
4. 教师接受第二次提交后，不点击“生成归档”；测试等待后台 worker 自动完成归档，并从任务/API 状态确认 job 成功。
5. 下载归档 ZIP，核验包内清单摘要，并直接比较第二次提交候选 DOCX、冻结提交 DOCX、归档 `final.docx` 的 SHA-256 和内容版本身份。旧提交不得被新草稿覆盖。
6. 增加负例：检查证据摘要过期、成品字节变化、缺必填字段、未解决阻断批注、阶段关闭、归档任务失败/排队、下载越权、旧提交链接和 PDF 未生成；验证阻断或明确失败状态，不假绿。
7. E2E 报告记录源码 SHA、模板与规则摘要、浏览器/环境、测试账号角色类别、批次/提交/归档 ID（合成数据）、所有下载摘要及失败证据。不得在报告保存密码、token 或 Cookie。

**退出条件：**在本地隔离环境完成系统内写作 → 提交 → 退回 → 修订重提 → 接受 → worker 自动归档 → 下载校验；不依赖人工格式勾选，不依赖 PDF，不依赖整篇导入。

### 阶段 E：收敛文献与权限

1. 为 1101 冻结实际启用的参考文献标准/制度、版本、排序和编号规则，只开放实现和输出检查均已通过的选项。
2. GB/T 顺序编码制、GB/T 著者—出版年制、APA 7、IEEE 分别提供标准身份、字段事实、格式化、排序、编号/引用映射及切换测试。正文引用仍可选时按已确认的“引用可选扩展”执行，不能宣称为标准要求的全文引用规则。
3. 对粘贴文献覆盖来源类型、缺字段、语种/出版年待确认、重复文献、编号冲突、标准切换及无正文引用；未实现的格式不得出现在正式模板的选择器中。
4. 维持系统管理员、教师、学生三种开放业务角色。清理工作流中残留的 `college_admin` 角色授权分支，或通过统一服务端策略确保其不可达；前端隐藏菜单不能代替 API 权限。
5. 对登录及旧会话、批次/提交/批注/归档、原材料、Word、可选 PDF、归档 ZIP、审核候选及媒体资源执行角色 × 资源范围矩阵。教师只能访问有效指导范围；学生仅能访问本人资源；关闭角色直连 API 必须拒绝。

**退出条件：**试点实际启用的文献配置经规则、格式和 Word 产物检查；未启用标准不可被请求或选择；角色正向/反向矩阵通过。

### 阶段 F：生产只读核验与受控线上验收

1. 先只读核对当前生产 `/api/health/live`、`/api/health/ready`、`/api/version`、`/api/workflow-capabilities`，并从受控运维配置/运行环境确认 `PAPERGUARD_DELIVERY_STAGE`、部署 SHA、worker 服务状态及日志。未知或缺省 stage 不能按试点正确配置推断。
2. 查阅现有失败/排队 `archive.generate` 任务的 job、archive、提交、错误码和日志，确认是否仍存在及是否有重复生成风险。不得直接重试历史任务；重试、改变任务状态、创建线上测试批次或清理测试数据均需明确目标及授权。
3. 在发布门禁、备份与回滚演练通过并取得对应变更授权后，使用新的隔离合成批次执行阶段 D 的线上闭环；确认 worker 使用正确 stage 并自动完成归档。
4. 线上核验版本身份与当前部署 SHA 一致；保存健康、能力、API/浏览器结果、归档 job、提交及归档摘要对账证据。学生、教师、系统管理员分别执行其批准的操作，另用关闭角色和无关学生执行拒绝路径。
5. 生产部署、stage 配置、数据库或任务状态修改不属于本方案文件编写授权，须依据仓库发布流程单独确认、备份和执行。

**退出条件：**线上代码/前端制品身份明确；阶段和 worker 配置一致；受邀测试账号完成真实师生闭环；提交 DOCX 与归档 DOCX 摘要一致；正向和越权负例均有证据。仅有本地/CI/健康检查不能提升为线上业务验收。

| Word原生试排 | 最终 DOCX SHA、Word/OS/字体、分页输出或布局证据 SHA | 对应固定 Word 环境的分页和目录/页码事实 | 生产节点和师生浏览器流程 |
| 浏览器E2E | 当前源码 SHA、1101 准入摘要、测试环境、合成业务 ID、下载 SHA | 系统内写作到 worker 归档的本地用户路径 | 生产版本、真实学生数据或未执行的 Office 基准 |
| CI/发布门禁 | 最新提交 SHA、工作流运行 ID、所有必需检查结果 | 该提交对应的构建和自动门禁 | 已部署、已启动、生产 UAT |
| 生产UAT | 部署身份、stage、worker 环境、合成批次/提交/归档身份、在线结果 | 该生产版本指定范围的线上操作 | 未测角色、未测模板、未测异常路径 |

## 6. 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 90% 口径缺少分母和硬阻断集合 | 可能把关键错项平均掉，或分数无法复现 | 阶段 A 固定适用单元、排除依据和硬阻断清单；报告原始明细 |
| 当前 E2E 走错模板/输入路径/归档动作 | 即使测试通过也无法证明实际需求 | 阶段 D 重建对齐 1101 与系统内写作的主流程 |
| 真实 Word 证据不足 | 目录、页码、分页和字体问题进入成品 | 阶段 C 由固定 Word 环境生成并绑定布局证据；缺失即不能声称通过 |
| 多文献标准承诺超出实现 | 学生选到错误排序或错误著录格式 | 阶段 E 仅开放通过的标准；逐标准增加能力后再开放 |
| 工作流角色分支不统一 | 非开放角色可能暴露操作或出现误导性界面 | 认证统一拒绝并补全后端资源矩阵；清理遗留分支 |
| 生产 stage/worker 未知 | 任务不生成、积压或使用错误版本 | 阶段 F 先只读核对真实环境；线上任务变更前审批 |
| 工作区改动未形成可复现快照 | 旧 CI 与当前代码无法对应 | 阶段 A 先固定源码身份，再跑测试、E2E 和发布门禁 |

## 7. 待确认或后续决策

以下事项不阻止形成方案，但必须在对应阶段退出前冻结：

1. 1101 各条格式检查单元的计分粒度，以及哪些属于不可容忍格式项、哪些进入 90%计分项。
2. 生产 Word 节点的操作系统、Word 版本、授权方式、运行隔离和故障恢复方案；当前不能从 Mac 本机环境推断。
3. 试点正式开放的参考文献标准列表。平台目标可以支持多标准，但每项需单独验收后才可开放。
4. 当前生产中历史失败/排队归档任务是否仍存在、是否需要恢复，以及具体恢复授权。

- 不把 PDF 设为学生必交件或师生闭环前置。

- 不启用 1101 试点已明确排除的 OCR、图片重建、原生公式/图表、脚注/尾注、可编辑代码块。
- 不在本方案阶段修改生产配置、重试/删除生产任务、部署、迁移数据库或发布代码。
- 不以教师人工格式核验代替系统能力，不将普通模板或旧版本证据表述为 1101/当前生产已通过。
