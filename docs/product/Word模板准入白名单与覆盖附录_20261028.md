# PaperGuard 模板准入白名单与覆盖附录

日期：2026-10-28。关联[需求模型 §10.1](./Word写作与模板导出需求模型_20261028.md#101-可证伪的模板准入)。本文保存结构白名单的技术记录、审批和覆盖细则；准入原则以主文档为准。它是待实施的验收契约，不代表白名单已建成。

## 1. 基线与独立盘点

基线依据[配置与恢复附录 §6 的 S-07～S-09](./Word写作与模板导出_配置与恢复附录_20261028.md#6-官方来源与核对范围)：ECMA-376 的词汇、包及兼容规范、微软实现/扩展说明，加上固定 Word 环境生成的真实样本。规范允许某结构不代表本系统支持。先建设、验证常见 DOCX 基线，再准入模板；不从空白名单启动后宣称任意模板可发布。

盘点在高层语义解析器之外执行，记录全部包条目、内容类型、关系、XML 命名空间/元素/属性、字段、扩展及 `AlternateContent` 分支的数量和位置。不得在解析器丢弃未知内容后盘点。兼容标记的选择、回退、保留行为须绑定声明的 Word 环境；`mc:Ignorable` 不构成本产品的自动验收豁免。

## 2. 白名单条目与版本

| 记录项 | 必须说明 |
| --- | --- |
| 身份与上下文 | 部件/关系类型、元素或属性 QName（命名空间 URI＋本地名）、父子/所在区域及有效上下文 |
| 值与版本边界 | 属性/值约束，适用标准、Word 及兼容声明版本，不允许未经审查的命名空间通配 |
| 处理契约 | 解析、填写、保护或明确排除的行为；语义/版面影响类别及理由 |
| 来源与证据 | 权威条款/实现说明、样本摘要、结构保护、固定 Word 成品与适用布局、未知/越界失败证据 |
| 治理 | 提交人、独立复核人、负责人/备份审批人、批准记录、版本和变更理由 |

`rsid`、校对标记可逐项评估为受约束元数据，仍须记录保留规则；书签可能是引用目标，不能笼统删除。`w14/w15` 等扩展逐项判定，不能整个命名空间视为无影响。未知项进入适配清单并阻断，不以“原件还在”或“该样本没用到”证明其已可验证。

白名单按不可变版本、摘要和变更记录发布；模板准入与成品凭据绑定所用版本。新增或修订先分析受影响模板/输入/历史凭据并复验，不能静默把新版覆盖到旧结论。

## 3. 审批与备份职责

1. 系统团队提交新增条目及上述证据；教师仅确认规则含义与范围，不审批技术豁免。
2. 由非提交人的技术复核人检查结构语义、内容保护、实际成品和负例证据，并留下结论。
3. 技术负责人批准；负责人不可用时由已登记的备份审批人代批，记录代批依据。同一人可以兼复核和批准，但不得复核/批准自己提交的条目；缺少独立人员时保持待审批，不自批或借教师勾选放行。
4. 审批角色及备份名单由系统团队维护，发布前须实际配置；批准只接受证据支持的范围，不能把未知任意值批成已支持。

## 4. 有限覆盖规则

- 每种实际结构、允许输入类别、版式区域、有效样式/继承链、分节和规则边界至少有单项覆盖。
- 组合覆盖模板实际相邻结构、跨页/跨节及已知高风险交互，例如图与图题、标题与后文、引用目标与编号作用域。长封面、跨页表格、公式/注释、附录及混合文献按实际与允许输入纳入。
- 不要求全排列。额外组合按预先记录的风险条件扩展；覆盖表记录选择理由、未覆盖边界及批准人。未覆盖项仍在允许范围内时，须补证据或提供可审查的不影响必检结果依据，不能自动略过。
- 清单逐项关联识别、填写/保护、布局与独立检查；冻结样本、期望、输入及结果摘要。正常样本须可交付，未知结构、对象遗漏、错误编号/分页与证据缺失须可触发失败。
- 通过数或单篇样稿成功不能代替能力覆盖；不得用“不适用”消掉缺项。不适用须有规则来源与范围理由。

## 5. 试点引用

初始输入来自[1101 规则与结构清单](./Word试点_1101规则与结构清单_20261028.md)和[4.7 内容清单](./Word试点_4.7内容类型清单_20261028.md)。二者仅是只读盘点基线，尚须与教师允许输入取并集并完成规则澄清、技术验证及审批，不能把清单文件存在当成准入已通过。

## 6. 视觉指标与计量

本节承接需求模型 R-09/§10.2 的工程计量细则；仅对已确定适用的学校规则或明确标识的工程要求执行，不给全部截图附加规范。

- 使用冻结标注集，记录字符替换、删除、插入错误：`CER=(S+D+I)/N`。`N` 按冻结字符计数/归一化规则计算；漏识别计删除，失败样本不得从分母移除。无文字样本另计虚假文字检出，不计算 CER。
- 报告文字区域检出率、对象绑定覆盖率、漏检及误通过率；语言、公式/上下标、小字、旋转和噪声分别报告，不能用总体均值掩盖必需类别失败。
- 有可靠源文本时，必需字符（含单位、上下标）逐项核对；OCR 结果不能同时作真值。对象分母来自独立结构清单，来源绑定和适用检查覆盖率须为 100%。
- 有效分辨率按像素数除以输出英寸计算，尺寸用模板允许的物理单位；可读性配置须定义最小文字像素高度、有效分辨率等可重复条件，像素高度不等于字体点值。
- 系统团队冻结测量单位、数据集/适用范围、计算方法、阈值、容差、失效条件及版本，经评审后用于准入；具体数值尚未完成验证，不能用“精确识别”代替。
