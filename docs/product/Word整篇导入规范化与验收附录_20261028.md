# PaperGuard 整篇 DOCX 导入规范化与验收附录

初次日期：2026-10-28；当前修订：2026-10-29。本文细化[需求模型 R-24](./Word写作与模板导出需求模型_20261028.md#r-24-整篇已有论文-docx-可选迁移入口)这一可选迁移入口；是验收要求，不表示现有导入器已支持。原件保留及数据清理按主文档 R-22，入口开放按 §12.1。学生确认内容事实，系统负责规范化、映射和格式检查。

## 1. 类别级规范化

预览按类别显示数量、位置及代表例，可展开全部定位；每类给出保留、转换、排除和待恢复数量及理由，批量确认后记录决策摘要。正常版面转换不要求逐空段或逐换行点击；有事实歧义或未支持结构的项单列恢复。所有操作保留源到目标映射，不因“噪声”分类跳过源内容盘点。

| 类别 | 默认策略及批量决策 | 不可静默处理的边界 |
| --- | --- | --- |
| 空段落与间距 | 识别仅供版面间隔的空段，转为目标模板间距或声明排除；预览显示来源位置及数量 | 含分节、分页、字段、图片、书签/引用目标的段落先迁移关系；空表格单元格保留行列；空标题样式不生成章节。空白不是充分删除条件 |
| 前导空格/制表符 | 有证据为段首缩进或对齐时，转换为语义段落/封面字段，再由模板排版；批量声明转换 | 代码缩进、公式对齐、表格内分隔及合法正文空白不能套用；无法判定时展示上下文并保留待恢复，不裁掉字符后称完整 |
| 手动分页/源分节 | 作为来源版面意图登记，由目标母版的章节/分节规则重排，清单声明不沿用源页位置 | 附录、横向表或特殊区域的语义先保留，规则冲突需恢复。事实文字和固定标识不可随源页眉/页脚一起丢弃 |
| 软回车 | 段内语义换行保留；明确为视觉折行的可批量转换，保持词间边界及前后顺序 | 诗句、地址、清单、单元格内行及引用原文等不按视觉折行合并；无法判定时保留，母版约束无法满足则进入恢复 |
| 修订痕迹 | 显示插入/删除/移动及格式修订分类数量，学生一次选择“接受全部”“拒绝全部”或回到 Word 处理后重传；选定后生成新的候选摘要 | 系统不默认选择事实视图；选定视图须覆盖文字、表格/结构及格式修订。未知修订构造、移动配对失败、视图冲突保留待恢复，不只处理插入/删除后宣称全部处理 |
| 隐藏文字 | 按直接属性、样式继承/docDefaults及兼容分支盘点；默认不进成品，学生按类别确认，可展开选择必要文字恢复为可见正文 | 排除不得破坏书签、引用或其他对象关系；恢复后重新规范化并检查。原件保留，不以不可见等同不存在 |
| 来源批注 | 默认不进成品，展示数量、锚点/范围及上下文并批量确认；必要批注文字可显式恢复为正文，标记来源 | 无法定位或无正文锚点的批注仍列明；与 M2 教师对新提交生成的应用内批注分开保存，不能混成已完成审核 |
| 超链接 | 保留显示文字及已验证安全的目标关系；原 TOC 内链作为派生缓存排除并由目标目录重建，正文内部引用转换为稳定目标 ID | 危险/未知协议或无法映射目标进入待恢复；学生可显式转纯文字、改目标或删除。系统不自动访问外链，危险目标不带入成品，合法显示文字不静默删除 |

批量确认不能豁免对象缺失、危险目标、未知结构或悬空引用。可保存候选/草稿，但仍在论文中的未解决项阻断正式导出。更改修订视图、恢复隐藏文字或换源文件后，重建候选与相应确认；不能复用旧候选确认覆盖新内容。

## 2. 样本集合与覆盖

4.7 为首篇基准。完整导入工程验收的最小真实集合为**至少3篇、3位作者、至少2个专业**，合计覆盖自动、手工及混合标题/编号习惯；实际样本及预期在执行前冻结。这是最低覆盖方案，不是导入所有论文的保证，也不以作者数量代替结构覆盖。

| 样本组 | 必需覆盖 | 当前材料状态 |
| --- | --- | --- |
| 4.7 基准 | 混合标题/自动章号/手工5.3、空标题反例、4张表（1封面＋3内容）、27图题对/26媒体、1个SEQ及手工旧号、重复号和正文引用、多分节/目录缓存 | 用户授权的原件已到位；静态清单完成，产品导入和成品仍须实测 |
| 其他真实论文 | 补齐不同作者、专业、纯自动/手工编号及正文结构；均须有使用授权，控制身份字段及原文访问 | 至少再2篇待授权提供，不扫描本机其他学生目录或用已有材料改名充数 |
| 受控变体与负例 | 类别规范化、修订接受/拒绝、样式继承隐藏、批注恢复、超链接、空单元格/锚点、歧义图题、范围外及未知OOXML、损坏包 | 尚待建立；可用脱敏合成样本，不计作真实作者/专业多样性 |

每种已开放结构和规范化类别至少有一个正例及相关失败/恢复例；不存在于4.7中的类别必须补样，不能用计数0当支持证据。组合覆盖实际相邻、跨表/页/节及高风险交互，沿用[白名单附录 §4](./Word模板准入白名单与覆盖附录_20261028.md#4-有限覆盖规则)的有限覆盖准则。

最小真实集合、允许范围及负例未满足，不得报“通用导入验收通过”，也不得开放该可选导入入口。4.7单篇可先定位缺口并建立内部证据；M1 系统内写作的受邀生产开放按主文档主路径验收和共同前置决定，不因未开放的可选导入能力受阻。

## 3. 导入成功率与恢复指标

试点观察指标，不先承诺百分比 SLA。记录样本来源许可、匿名样本 ID、源摘要、导入器/规范化配置、模板/合同版本、尝试 ID、确认/恢复步骤、结果和耗时；不在公开报告保存身份、原文或凭据。

| 指标/状态 | 定义与分母 |
| --- | --- |
| 合法输入总量 | 按源摘要及配置版本去重的实际上传；同一文件重复点击/网络重试不增加样本量，尝试次数另记；源内容变更明确关联原件，不能当新作者样本 |
| 范围内集合 N | 合法输入中符合已冻结输入合同的全部样本。即使解析器失败也计入，不能依据解析成功与否反推范围；未知特性须显式分类、留依据，已承诺能力不能事后改成范围外 |
| 首次完整导入成功 S | 首次尝试完成全部源内容/关系对账、必要事实/视图确认并应用新修订；无静默丢失及未解决项。按预期完成事实确认不算技术恢复；接口200、预览部分成功或只存草稿不算 S |
| 首次成功率 | S/N；同时公布 N、S、失败、待确认/待恢复、放弃数和分组情况。尚待用户处理的项留在分母并单列，样本未结案时标“阶段观察”，不把它伪判技术失败或偷偷剔除 |
| 恢复后完整导入 | 修正/重传/系统修复后最终完整导入数及其分母、恢复次数/原因。与首次成功分别列报；源文件更改和配置升级不得覆盖原失败事实 |
| 范围外/损坏/拒绝 | 在合法输入总量外/内分别列数量、依据和可操作恢复；不混入范围内成功率，也不从总体结果表消失。上传前取消单列，不计成一次解析成功 |
| 端到端交付 | 另记导入后成功生成1101 DOCX、Word 布局并通过独立检查的数量/同集合分母；用户请求 PDF 时再另记可选 PDF 成功率。完整导入成功不等于格式成品或 M1 已通过 |

按编号习惯、专业、内容类型、规范化类别和失败原因拆分，保留第一尝试与最终结果。小样本需报告数量，不能把三篇全过推广为稳定成功率；失败/放弃原因未知时如实记录。针对正确输入的误拦截、部分丢失和范围外静默放行分别观察，不能用平均成功率遮盖完整性失败。

## 4. 4.7 正式路径与证据

1. 通过正式网页在隔离测试项目上传原件，记录运行工作区、源码/配置摘要及源摘要；现有服务版本与待验文件不一致时标明，不能借用其结果批准当前代码。
2. 导入预览逐项对账标题树、正文/富文本、表格及图题/引用；核对自动章号、手工5.3、空标题和表格小数反例。4张表去向必须解释，27出现位置不能去重成26对象，正文说明句不误当第28个题注。
3. 类别规范化与修订/隐藏/批注确认绑定候选；源目录/页眉页脚/分节不污染1101。唯一SEQ与其他手工旧号均转稳定ID；重复图5.12及正文歧义由学生确认，合法误报可局部标非引用。
4. 确认应用新修订后再对账，不修改既有学生稿；通过1101导出、固定Word排版和独立检查验证全文完整性、格式、目录/页码和对象引用。用户请求 PDF 时另行验证其与冻结 Word 成品的摘要/页数绑定。离线解析或手工逐块粘贴另记，不代替此路径。
5. 证据分别标识静态输入、产品预览、应用、成品检查、Word布局和开放状态；未执行项明确“未验证”。问题定位到导入阶段和类别，记录最小复现及下一步，不为跑通而放宽门禁或修改源件。
