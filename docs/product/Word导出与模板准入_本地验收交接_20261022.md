## 状态分类

### 已实现

- 模板准入报告包含模板定义摘要、模板版本、源 DOCX 摘要和准入算法版本；候选确认、发布/绑定和相关模板入口会重算或校验评估。前端在定义改变后显示评估过期状态。
- 最终 DOCX 报告包含检查器版本、项目内容摘要、模板摘要、源模板摘要和输出摘要。同步响应携带这些结果；异步下载要求制品、冻结快照、源模板和重新计算的检查身份相符。归档下载还会从归档关联的冻结项目版本重新解析源模板并读取当前源文件；源文件被替换、删除或绑定变化时返回 409，不能复用旧归档的通过凭据。
- 嵌套样式准入已覆盖 `styles.*`、`sections[*].style`（递归章节）、`cover_blocks[*].style`、封面字段 `label_style` / `value_style`。非法或无法核验的样式约束会在模板确认前阻断。
- 上传 DOCX 在解压前执行 ZIP 大小/压缩比限制；XML 解析禁用外部实体和网络访问，并拒绝 DTD。

### 有意阻断或明确不支持

以下情况应显示为阻断/不可核验，不得表述成“已支持”或“暂时通过”：

- 封面表格块、带原始表格的源 DOCX、`source_xml` 复杂表格。
- 源 DOCX 中的 OMML 公式，以及多分节但没有显式映射的复杂页面布局。
- 不受支持或无法核验的样式属性，包括嵌套章节和封面字段中的同类属性。
- 未映射的页眉对象/内容，以及不是受支持简单页码域的页脚。
- 通用锚点渲染缺少可用锚点时的富内容章节。

拒绝模板准入或拒绝输出下载只是保护门禁，不等于该能力已经实现。

### 尚未实现或覆盖不足

- Word/WPS 渲染引擎、自动刷新域、视觉分页比较，以及跨 Word/WPS/操作系统/字体环境的等价性证明。
- Office 图表对象的数据/语义和视觉结果检查。目前代码有图片与结构化表格规则，没有图表对象的完整能力规则；源文档正文中的绘图/图表也没有单独的准入阻断项。成品阶段的 inline shape 数量核对可能令其失败，但这不等于准入阶段已可靠识别并阻断，因此该边界仍未闭合。
- 通用写作项目中的公式内容块可被渲染，但最终检查器将其标记为未支持/不可核验，不能作为已交付的公式支持。
- 通用锚点图片和表格的自动结构核对不覆盖所有 Office 视觉属性；锚点测试证明的是生成内容及部分包结构保留，不是视觉验收。

### 等待真实验收

- 尚未收到导师选定的真实模板文件，因此没有对真实模板做准入结果确认或最终导出验收。
- Word/WPS 的具体版本、操作系统和所需字体环境待提供。没有这些输入，目录/页码域、分页、跨页表格、裁切/溢出的状态保持 `UNVERIFIED`。
- `backend/tests/fixtures/templates/admissible.docx` 和自动生成的 GB7713 结构样本是测试夹具，不是导师批准的真实模板。官方 GB7713 测试样本包含当前阻断的源表格，测试目标是确认其被拒绝，不能当作通过样本。

## 模板与报告失效规则

- 模板定义、版本或源 DOCX 字节任一变化，准入摘要都会变化；旧报告不能用于确认新候选。编辑器和模板包页面也会在输入变化后显示过期状态。
- 导出报告绑定项目内容快照、模板摘要、模板源文件摘要、检查器版本及最终 DOCX 字节。异步下载会对冻结快照重算；文件或绑定变化时返回冲突，不下发旧报告对应的文件。
- 证据位置：`backend/app/services/template_admission.py`、`backend/app/services/docx_output_check.py`、`backend/app/api/templates.py`、`backend/app/api/projects.py`、`backend/app/api/document_projects.py`、`backend/app/api/workflow.py`；回归用例见本文件“验证记录”和“改动路径”。

## 导出/下载入口核对

| 路径 | 成品检查/下载校验 |
|---|---|
| `POST /api/projects/{proj_id}/export` | 同步导出；最终 DOCX 静态检查失败或不可核验时返回 409，不返回文件。`force=true` 不绕过此检查。 |
| `GET /api/projects/{proj_id}/export-jobs/{export_id}/download` | 校验制品摘要、冻结项目/模板/源文件身份，并重新检查输出报告。 |
| `POST /api/document-projects/{project_id}/render` | 通用文档同步渲染；成品检查未通过或不可完成时返回 409。 |
| `GET /api/document-projects/{project_id}/render-jobs/{render_job_id}/artifact` | 校验异步产物摘要、快照、模板版本/源文件绑定和重新计算的报告身份。 |
| `GET /api/workflow/archives/{archive_id}/download` | 校验归档 ZIP 成员和清单、每个成员摘要、归档身份及 `final.docx` 检查凭据；重新读取冻结版本源模板并比对 `source_template_sha256`。 |

仓库中没有另一个独立 DOCX 文件下载路由；以上覆盖项目导出、通用文档渲染和流程归档的可下载产物。导出预览只返回清单，不是文件下载入口。
