# Word 导出检查器能力矩阵

范围：静态检查器读取最终 DOCX OOXML，并按冻结模板与项目快照核验实际输出。此矩阵只覆盖本地自动检查可证明的约束，不代表 Word/WPS 已刷新目录或完成视觉分页验收。

## `TextStyle` 属性覆盖

每项属性都对应至少一条输出诊断规则。检查器对实际输出的封面段落、章节标题、正文段落、图表题注和结构化表格单元格按所绑定的模板样式执行检查。

| `TextStyle` 属性 | 核验规则 | 核验证据 |
| --- | --- | --- |
| `font_zh` | `format.font_east_asia` | 读取每个非空 run 的东亚字体及继承值 |
| `font_en` | `format.font_ascii` | 读取每个非空 run 的 ASCII/HAnsi 字体及继承值 |
| `size_pt` | `format.font_size` | 读取每个非空 run 的字号 |
| `bold` | `format.bold` | 读取每个 run 的有效粗体状态 |
| `italic` | `format.italic` | 读取每个 run 的有效斜体状态 |
| `underline` | `format.underline` | 读取每个 run 的有效下划线状态 |
| `align` | `format.alignment` | 读取段落对齐方式 |
| `line_spacing`, `line_spacing_rule` | `format.line_spacing` | 读取行距数值与 OOXML `lineRule` |
| `space_before_pt`, `space_after_pt` | `format.space_before`, `format.space_after` | 读取段前、段后间距 |
| `first_line_indent_chars`, `hanging_indent_cm` | `format.indent` | 读取字符缩进或长度缩进，并遵循 OOXML 优先级 |
| `color` | `format.font_color` | 读取 run RGB 颜色；模板颜色为空时按导出约定核验黑色 |
| `highlight` | `format.highlight` | 读取 run 的 OOXML 高亮值 |
| `vert_align` | `format.vert_align` | 读取上标/下标值 |
| `page_break_before` | `format.page_break_before` | 检查段前分页属性、显式分页符或下一页分节边界 |

`TEXT_STYLE_COVERAGE` 与 `TextStyle.model_fields` 做集合相等测试，防止模型新增属性但能力矩阵遗漏。

## 模板准入与 Office 复核

模板准入已接入本地模板导入、编辑、候选确认/发布、模板列表、论文创建、阶段配置和学生绑定入口。`POST /api/templates/admission/assess` 对编辑中的旧式论文模板做只读评估；`POST /api/templates/parse/assess` 对通用 DOCX 候选做只读重评估。两者都不会保存候选或模板。

每份报告包含规范化定义 SHA-256、实际源 DOCX SHA-256、版本及组合评估摘要。候选在确认和打包发布时由服务端重算；版本定义或源文件变化后摘要不匹配，必须重新评估并确认。通用模板的摘要同时保存在发布版本扩展信息中。

`office_review_required` 表示当前结构没有静态阻断项，可以进入写作草稿，但仍需在 Word/WPS 检查最终分页、字体替换、表格跨页/裁切并更新目录与页码域。该状态不是 Office 验收通过。所有报告的 `can_claim_compliant_delivery` 均为 `false`；最终 DOCX 检查仍单独作为同步、异步及归档交付门禁。

当前准入器会阻断：封面表格块、多字段复合封面块、未映射的源 DOCX 表格/OOXML 表格片段、OMML 公式、含内容的未映射页眉或复杂页脚、多分节源布局、源文件缺失/摘要不一致，以及当前成品检查器不支持或无法识别的显式样式约束。样式扫描覆盖模板默认样式、任意深度章节覆盖样式、封面块样式以及封面字段的标签/取值样式。源 DOCX OOXML 部件先通过现有上传压缩包预算校验，再以禁 DTD、禁实体解析、禁网络且不启用大树模式的解析器读取；无法安全读取时阻断准入。旧模板可以保留在管理列表中用于修订，但不能创建新论文、配置到阶段或供学生绑定。

## 输出对象映射

| 输出对象 | 绑定的样式 | 检查范围 |
| --- | --- | --- |
| 普通封面字段 | `cover_meta` | 内容、段落样式及所有 run 样式 |
| 单字段封面块 | 字段 `value_style`、`label_style` | 内容、段落样式，并按 label/value run 顺序逐项核验 |
| 封面静态文本 / spacer | block `style` | 文本或空段落、段落样式和分页约束 |
| 章节标题与正文 | 章节节点样式或对应 `template.styles` 样式 | 标题语义、段落格式、每个 run 的字符格式 |
| 自动生成或相邻图题 | `figure_caption` | 题注文本、段落格式和 run 格式 |
| 自动生成或相邻表题 | `table_caption` | 题注文本、段落格式和 run 格式 |
| 结构化普通表格 | `table_cell` | 表格行列、网格尺寸、单元格文本、单元格段落和每个 run 的完整格式 |

相邻的编号图题/表题与前一个图片/表格块按位置识别；渲染时按对应题注样式排版。相同文本的 inline run 以序号关联来源 run，不使用文本相等查找，避免同文异样式错配。

章节正文中的参考文献、致谢和附录条目继承对应段落样式，但章节分页约束归属于章节标题；检查器按实际导出映射检查标题前分页，不会要求每一条目都分页。

## 拒绝条件与边界

- 未知的 `line_spacing_rule`、非法颜色、未知高亮或未知垂直对齐会生成 `unverifiable` 能力诊断并拒绝发布。
- 无法按模板边界关联的封面 run 或 inline run 会标为 `unverifiable`，不跳过字符样式检查。
- 封面多字段表格、`source_xml` 复杂表格、合并单元格、公式 OMML、未映射页眉/页脚内容仍处于不支持范围；门禁拒绝这些输出。
- 目录检查验证域指令、缓存结果和刷新设置，不证明 Office 已刷新缓存。
- 自动检查不判断 Word/WPS 的最终视觉分页、字体替换效果或跨页表格展示。

## 负例与覆盖测试

`backend/tests/test_docx_output_check.py` 覆盖全部属性映射、颜色探针回归、未知显式约束、封面字号/字体/对齐损坏、表格单元格及题注格式损坏、分页符损坏，以及重复文本 run 的位置关联。`backend/tests/test_template_admission.py` 覆盖可进入草稿的正例、封面/源表格、原始 OOXML、公式、页眉、默认/章节/封面嵌套样式正负例、DTD/外部实体与压缩比异常源文件，以及定义/版本/源摘要变化。模板解析 API 和项目/阶段入口测试验证候选不被确认、模板不进入学生写作。`backend/tests/test_writing_api.py` 验证最终输出检查仍是同步导出发布门禁。
