# 教师个人写作与学生指导

2026-10-12 用户确认的产品边界。本地实现与回归记录见 `../evidence/personal-writing-guidance-20261012/验收记录.md`；不代表已经上线。

| 用途 | 教师入口 | 操作与使用者 |
| --- | --- | --- |
| 教师自己写论文、申报书等 | 个人写作 → 设置自用文档模板 | 上传 Word 模板，可选附加文档规范；人工确认后保存为教师本人的自用模板。 |
| 教师自己的文档 | 个人写作 → 我的通用文档 | 选择本人模板或适用的已发布共享模板，创建、继续编辑、检查及导出自己的文档。 |
| 指导学生写论文 | 学生指导 → 发布论文模板 | 配置论文结构和排版要求；保存的论文模板在学生论文任务的阶段配置中选用，沿用提交、审核及归档流程。 |

两种用途分别使用通用文档包与论文模板流程。保存自用模板不会发布为学生论文模板；自用文档也不会自动成为学生论文任务。

教师新解析的通用模板、规范候选及新保存的通用文档包标记为个人用途。服务端按已登录教师的真实 ID 记录所有者；其他账号不能列出、直接读取、确认其候选或用该包创建文档，客户端指定“共享”或伪造所有者不能改变这一边界。自用文档模板页面使用“保存”文案。

已有明确发布的共享通用文档包保留原组织可见范围，界面标明“已发布的共享模板”；本次不重新归类存量数据。已创建文档继续沿用所有者、管理员及有范围权限的学院管理员访问策略。

本次未修改数据库迁移账本，不改变单学校试点的交付边界。
