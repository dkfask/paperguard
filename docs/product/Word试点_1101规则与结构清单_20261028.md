## 1. 定位与证据口径

`pN` 为 `word/document.xml` 中 `//w:body//w:p` 的一基序号，包含文本框及兼容分支后代；不是页码或可视段落数。规则有三类：**明确说明/批注、观察到的格式、样例内容**。观察值与示例不得自动推广为统一学校要求；冲突由教师澄清，技术可执行性由系统团队验证。

## 4. 已裁决的试点规则与边界

2026-10-28 用户通过问题弹窗确认以下规则；这是产品/语义决定，不是技术准入或真实成品通过证明。清单保留原样本冲突，实施时按本表生成可执行规则及来源映射。

| 项目 | 生效决定 |
| --- | --- |
| T-05 数字字体 | 各级标题及正文的阿拉伯数字 Times New Roman；字号和粗斜体随所在文字；中文/西文按区域规则。混排及生成编号按字符运行应用和复检 |
| T-06 标签/大小写 | 中文“关键词：”加粗；英文“Key words:”首字母大写；关键词内容保留专有名词大小写，字体按对应摘要区域 |
| T-08 内容提示 | 毕业年度 Y 取封面答辩日期年份，Y−2～Y 内至少15篇，其中英文至少5篇；早期文献作补充保留。按已确认出版年/文种展示总数、窗口内数、窗口内英文和未知/待确认项及统计完整性；缺答辩日期或有歧义时提示窗口待确定，不代填。T-08指标未达或统计不全不阻断交付；排序必需事实另按R-13，内容提示交M2教师审核 |
| T-09 文献优先级 | 著录标点、页码按所选标准；学校只控制字体/段落/悬挂缩进，新增覆盖须显式学校扩展。不能把批注56当作所有标准统一规定 |
| T-10 视觉边界 | 暂无统一图内字体/字号和逐字识别要求；保留原图并做有依据的尺寸/完整性检查。试点不启用 OCR、图片重建或外部识别，不要求逐图补录文字 |
| T-12 层级/目录 | 5.1.1/5.2.1 为三级，套母版标题3；内容来源保留完整层级/标题/顺序。源目录缓存排除后重新生成，不采用错误缓存或示例样式归属 |
| 说明框/批注 | 5个示例说明框及教师批注用于抽取规则，确认后从学生成品排除；排除项保留来源/理由/映射。学校标识和其他固定版式保留，兼容分支按逻辑对象去重 |
| 正式输入 | 系统内章节写作、粘贴和编辑是 M1 主路径；已有论文 DOCX 整篇上传作为可选迁移入口，按 R-24 单独验收 |
| 暂未开放的新增内容 | 原生公式、脚注/尾注、可编辑代码块和原生图表；代码截图/现有图片正常支持。范围外导入保留并恢复，不能静默丢弃 |
| 其他写作入口 | 通用文档/教师个人入口本次仅草稿，关闭正式导出/成品下载/提交/归档；默认模板独立准入后再恢复 |

发布前仍需逐规则有效格式/单位映射、母版保护/排除声明、字符脚本和布局证据及 §12 共同生产前置；产品裁决不代替这些工程验收。
