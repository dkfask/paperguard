# PaperGuard 三角色测试用例

> 测准声明：以当前工作树实际实现为功能基线，用户确认的方案为目标边界；代码证据统一在附录。完整主链不等于所有参数或资源矩阵。

简介：管理员配置与归档、教师指导审核、学生写作与修订重提。
环境：运行器在本机启动独立前后端及 worker，当前前端端口 18772；下一轮端口以运行记录为准。账号由运行器生成并仅保存在进程；手工复验向本次测试负责人索取临时凭据，不复用真实账号。
术语：批次=一组指导任务；阶段=一个提交时间窗口；预检=正式提交前检查；快照=一次正式提交时的不可变版本；归档=正文及提交审核证据 ZIP。
图例：P0 核心主链、P1 常规及关键异常、P2 抽样。模拟失败和布局数据单列为模拟检查。异步判定 60 秒为本地测试有界等待，不是产品性能承诺。

## 1. 管理员

> 前置：运行器已创建独立本地环境、测试账号及本用例所需阶段状态；按前序主链建立状态。

- **TC-01-01 登录及改密** [P0]
  - 操作步骤: 从登录页输入运行器创建的管理员凭据，完成首次改密后再登录。
  - 预期结果: 进入管理工作台，退出后返回登录页。

- **TC-01-02 认证教师** [P0]
  - 操作步骤: 管理工作台→用户管理，找到测试教师，查看详情后通过认证。
  - 预期结果: 用户状态显示已认证，教师可进入指导端。

- **TC-01-03 组织和成员范围** [P1]
  - 操作步骤: 管理工作台→组织结构，新增“三角色测试学校”，将测试教师分配到该组织。
  - 预期结果: 列表显示组织，刷新后成员范围仍保存。

- **TC-01-04 归档生成** [P0]
  - 操作步骤: 提交与归档→找到教师已通过的测试论文，点击生成归档。
  - 预期结果: 任务进入队列，测试环境 60 秒内完成，未完成记阻塞或失败，不等同产品 SLA。

- **TC-01-05 归档下载** [P0]
  - 操作步骤: 在成功归档记录点击下载。
  - 预期结果: 获得非空 ZIP，包含正文、提交与审核证据，ZIP 校验无损坏。

- **TC-01-06 管理页面可操作** [P1]
  - 操作步骤: 工作台依次进入批次、规范、审计、运行管理和系统设置，打开各面板并切换分页。
  - 预期结果: 页面有有效主标题，控件可达，权限限制明确，无页面错误。

## 2. 教师

> 前置：运行器已创建独立本地环境、测试账号及本用例所需阶段状态；按前序主链建立状态。

- **TC-02-01 登录与模板导入** [P0]
  - 操作步骤: 教师登录→论文模板→上传学校 DOCX 模板→查看预览→确认创建。
  - 预期结果: 章节名称及层级可读，创建后进入模板编辑，解析结构保存。

- **TC-02-02 规范发布** [P1]
  - 操作步骤: 写作规范→新建规范，填写“三角色测试规范”和版本 2026.1，上传 PDF 后发布。
  - 预期结果: 参考文档可见，规范状态已发布。

- **TC-02-03 批次和指导关系** [P0]
  - 操作步骤: 流程中心→创建“三角色测试批次”，选择测试学校，打开批次配置并指定测试学生和教师。
  - 预期结果: 批次与指导关系保存，重新打开配置仍显示已保存数据。

- **TC-02-04 发布阶段** [P0]
  - 操作步骤: 在批次配置新增“终稿阶段”，选择导入模板，开放时间早于当前时间、截止晚于当前时间，预览并确认发布。
  - 预期结果: 阶段显示已发布，学生看到对应任务。

- **TC-02-05 审核材料** [P1]
  - 操作步骤: 审核台→过程材料审批，逐条点击通过学生已提交的四种材料。
  - 预期结果: 待审批列表减少，学生记录显示通过。

- **TC-02-06 退回理由校验** [P1]
  - 操作步骤: 提交与审核→打开测试论文，不填理由直接退回。
  - 预期结果: 提示填写理由，提交仍待审核。

- **TC-02-07 添加意见及退回** [P0]
  - 操作步骤: 打开论文审核，添加“请补充系统测试结论”，填写退回理由后退回。
  - 预期结果: 退回成功，学生看到需修改状态与意见，旧提交快照保留。

- **TC-02-08 通过重提论文** [P0]
  - 操作步骤: 刷新审核台，打开学生重新提交的测试论文，点击通过提交。
  - 预期结果: 提交已通过，管理员可生成归档。

- **TC-02-09 角色边界** [P1]
  - 操作步骤: 教师登录后尝试访问用户管理与系统设置。
  - 预期结果: 被路由守卫拦截，不能执行管理员操作。

## 3. 学生

> 前置：运行器已创建独立本地环境、测试账号及本用例所需阶段状态；按前序主链建立状态。

- **TC-03-01 任务绑定与确认** [P0]
  - 操作步骤: 学生登录→我的任务，打开测试阶段，开始写作，填写“三角色测试论文”并创建绑定，确认要求。
  - 预期结果: 任务显示论文名称与已确认状态。

- **TC-03-02 过程材料填写提交** [P1]
  - 操作步骤: 阶段任务→过程材料，依次填写任务书、开题报告、终稿说明和过程封面，上传测试文件并提交。
  - 预期结果: 四项材料成功提交，重开面板可下载附件或已填表单。

- **TC-03-03 正文编辑保存读回** [P0]
  - 操作步骤: 继续写作→导入测试 DOCX 并应用，修改系统测试段落，等待保存完成后刷新。
  - 预期结果: 正文修改保留，保存状态不再待保存。

- **TC-03-04 格式检查和导出** [P0]
  - 操作步骤: 写作页→检查论文→导出 Word；存在缺失内容时核对提示并按提示处理。
  - 预期结果: 检查面板可读，下载获得可打开的非空 DOCX。

- **TC-03-05 预检正式提交** [P0]
  - 操作步骤: 回到阶段任务→提交预检，确认提示后正式提交。
  - 预期结果: 提交成功，待审核状态与版本记录出现。

- **TC-03-06 查看退回意见** [P0]
  - 操作步骤: 教师退回后，进入阶段任务和提交历史，打开退回记录。
  - 预期结果: 需修改状态、退回理由和教师意见可读。

- **TC-03-07 修订重提** [P0]
  - 操作步骤: 根据退回意见补充系统测试结论，保存后重新预检并提交。
  - 预期结果: 出现新的正式提交，旧记录仍保留、可从列表打开，且新版本包含修订。

- **TC-03-08 学生权限边界** [P1]
  - 操作步骤: 学生登录尝试访问组织、用户管理、系统设置和运行管理。
  - 预期结果: 入口被拦截；他人提交与文件在后端授权测试中被拒绝。

## 4. UI与恢复

> 前置：运行器已创建独立本地环境、测试账号及本用例所需阶段状态；按前序主链建立状态。

- **TC-04-01 短表单弹窗** [P1]
  - 操作步骤: 从论文列表新建论文，打开组织编辑和用户详情。
  - 预期结果: 弹窗居中且大小适合内容，输入和主按钮在 390×844、900×600、1280×800 可操作。

- **TC-04-02 长章节标题** [P1]
  - 操作步骤: 上传含长章节名称及三级标题的测试模板，查看导入预览。
  - 预期结果: 标题换行完整、层级清楚，无顺序或样式映射等技术编辑列。

- **TC-04-03 保存失败恢复** [P1]
  - 操作步骤: 写作页修改内容，模拟一次保存失败后恢复网络，点击重试。
  - 预期结果: 输入不丢失，重试成功后保存状态恢复。

- **TC-04-04 加载失败恢复** [P1]
  - 操作步骤: 打开管理工作台时模拟一次请求失败，恢复后点击重试。
  - 预期结果: 错误提示明确，恢复后工作面可用。

- **TC-04-05 手机导航** [P1]
  - 操作步骤: 在 390×844 的浏览器中登录，打开导航并依次选择当前角色入口。
  - 预期结果: 导航及操作按钮可触达，不出现页面横向溢出。

- **TC-04-06 英文导航** [P2]
  - 操作步骤: 将语言切换为英文，打开三个角色导航分组和代表页。
  - 预期结果: 英文标签可读，导航分组与页面正确对应。

- **TC-04-07 键盘及自动无障碍检查** [P1]
  - 操作步骤: 在登录、三角色工作台、创建论文弹窗与审核页按 Tab 切换，执行自动扫描。
  - 预期结果: 焦点可见且可达，弹窗关闭恢复焦点，自动违规项目按等级列入报告。
