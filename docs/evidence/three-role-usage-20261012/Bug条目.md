## BUG-20261012-01 · 教师认证后详情仍为待审核（S2 / P1）

- 角色/入口：管理员，用户管理→待审核教师→查看详情。
- 复现：通过认证，等待保存和列表刷新，保持详情打开。
- 预期：详情显示已认证，不能重复执行同一认证。
- 实际：服务端查询返回 active；当前详情仍为待审核，仍有通过认证按钮。关闭再打开后才正确。
- E3：`usage-audit.spec.ts` 的 TC-01-02 失败断言；`screenshots/certification-after.png`。
- E2：`frontend/src/views/AdminUsers.vue:27` 保存 `selectedUser` 对象；`:33` 列表刷新替换 users 数组；`:37` 认证后仅刷新列表，未更新选中对象。
- 影响：状态反馈相互矛盾；相同模式也用于角色修改和身份申请，后两者未单独证明相同后果。
- 建议：以保存结果或最新列表中的同一 ID 更新详情，或成功后明确关闭详情。回归包含保持详情打开、关闭重开、失败重试和手机。
