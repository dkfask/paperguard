## 各轴执行物与限制

- 功能、状态、数据一致性：三角色真实流程，以保存读回、两次提交、审核、ZIP 下载作为判据。
- 权限/业务安全：角色 UI 路由检查与后端既有授权/匿名/跨资源测试；不声称全 SaaS 资源矩阵。
- 可靠性：已有浏览器注入保存/加载失败与恢复；真实 worker 成功路径和后端归档失败重试。
- 性能/并发：只读分页、锁/版本及 worker 调用面审查；不跑压测或宣称容量阈值通过。
- 兼容：仓库配置的 Chromium 桌面与手机模拟。Safari/Firefox 和实体手机不在已验证范围。
- 无障碍：P0 页自动扫描、键盘焦点抽样；完整读屏/合规结论不在范围。
- 视觉：已有关键页截图差异门禁不更新基线，同时归档三角色新截图供 UI 审查。
- 国际化：中文及英文导航与代表页面，非全语言主链。
- 集成：本地前后端、文件解析及 worker 调用；邮件、微信与外部 AI 仅记录未验证。
