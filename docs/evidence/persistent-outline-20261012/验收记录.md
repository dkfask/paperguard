# 章节大纲常驻页面修复验收记录

## 需求与问题

写作页的“章节大纲”被实现为右侧抽屉。打开后页面出现遮罩，正文被盖住；抽屉内部仍沿用窄侧栏宽度，造成右侧大片空白。章节大纲是写作时持续使用的导航，应与正文同时存在于写作工作区。

## 修复结果

- 桌面端：章节大纲固定在写作页左侧，正文占用剩余宽度，移除抽屉遮罩和关闭按钮。
- 窄屏：章节大纲改为正文上方的页面区域，保留滚动，不遮挡正文。
- 顶部“章节大纲”按钮保留为定位入口，点击只把焦点移到常驻大纲，不再打开弹层。
- 删除多余的三列空白布局，避免大纲与正文之间留下无内容区域。
- 章节选择、添加章节、移动章节、删除章节、字数统计和保存流程保持原有行为。
