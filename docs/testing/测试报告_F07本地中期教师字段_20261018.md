## 3. Bug 清单

### BUG-F07-01：已提交的中期记录无法由指派教师填写教师字段

- 现象：学生提交中期检查后，指派教师填写意见或评分时得到 409，教师字段无法进入正常审批链。
- 根因：原通用编辑路径只允许 draft/returned 状态；submitted 记录被拒绝，且没有单独的教师字段更新路径。
- 根因证据：代码路径和用户报告相符；本轮没有对旧候选额外重放基线，因此根因归类为基于实现与报告的推断。
- 影响：中期检查的教师意见/评分环节受阻；本轮未观察到数据丢失或越权写入。
- 修复：新增仅允许准确指派教师更新 advisor_comment、score 的专用 API；要求记录处于 submitted 且教师为下一审批人，校验 revision、字段范围和分数范围，并保留学生字段。学生表单和提交载荷仅包含学生字段。教师收件箱新增填写入口。
- 回归：backend/tests/test_workflow_api.py::test_midterm_teacher_fields_preserve_student_data_and_require_assigned_teacher；frontend/e2e/f07-midterm-teacher-fields.spec.ts。
