# R51 学生阶段说明与材料字段只读复核 — 2026-10-18

S-A 登录、身份核验、精确 participant 详情读取与退出均为 HTTP 200；participant 与 stage ID 匹配，阶段为 `published`。本次递归遍历 `stage/config` 下 24 个嵌套字符串叶，包括数组内容；只保留字段路径和结构，不保留阶段正文、材料名称值、学生身份快照值或论文内容。

接口中存在 `open_at`、`deadline_at` 字段和 1 个必需材料标识字符串，但没有独立的 `instruction`、`description` 或说明正文键。具体日期正确性、材料标签/说明的页面呈现、说明是否充分都未验证；API 结果不能证明 UI 没有其他说明。因此只能记录“接口未提供独立说明正文，实际说明充分性仍无法判断”，不能判定缺失或合格。F02 保持 `NOT RUN / partial`。
