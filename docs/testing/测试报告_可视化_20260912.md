## 2. 修正的测试缺陷

原测试将整个 `main` 作为 Playwright `mask`，导致基线图主体区域全部为默认洋红色遮罩，无法证明页面主体已正确渲染。

已将遮罩缩小到动态数据区域：

- 用户托盘、身份和汇总计数
- 工作台任务标题、提交编号、日期和动态操作区
- 归档页 `.archive-row` 动态标题、提交号和时间

归档页首次普通回归发现 `1454` 个像素差异，根因是归档页实际使用 `.archive-row`，原有 `.task-row` 遮罩未覆盖动态标题和提交编号；补充精确定位器并重新生成基线后，桌面视觉回归通过。该差异归类为 `TEST-DEFECT`，不是产品缺陷。

另外，测试流程补充了两类异步稳定性等待：真实章节内容填写后等待 Writer 自动保存完成；文件上传响应完成后等待页面成功状态。截图断言将字体等待上限提高到 `15s`，未放宽像素差异阈值。
