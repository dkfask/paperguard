## 本地代码做了什么

此前审阅页骨架已在 `miniprogram/src/pages/review/index.vue`，但教师闭环有缺口：

1. 教师任务列表不区分待审核/待复核，也不展示学生姓名与等待时长。
2. `GET /api/my-tasks` 与提交详情里的 participant 缺少 `student_name`、`current_submission.submitted_at` / `review_cycle`。
3. 通过按钮只看人工确认和阻断批注，不看候选版本 `ready` 与阻断门禁。
4. 退回只强制原因，修改要求与修订截止可空。
5. 批注未按「必须处理的阻断 / 普通建议 / 已解决」分组；正文不能引用段落。

本切片改动：

- 后端 `_task_view` 增加 `student_name` 与更完整的 `current_submission`；提交详情的 `participant` 复用该视图。
- 抽出 `miniprogram/src/utils/teacher-flow.ts`，任务页/审阅页消费同一套规则。
- 教师消息里的提交/批注跳转到审阅页。
- 结构检查覆盖审阅页与 MP2 token；`test:flow` 同时跑 MP1/MP2。
