## 4. 发现的缺陷

### BUG-COLLEGE-SCOPE-001 / 002（打开）

- 现象：计软学院管理员可以给对照学院创建并发布写作规范（HTTP 201 / 200）。
- 期望：规范绑定超出本人学院范围应 403。
- 对照：同一账号查看对照学院批次返回 404，审计也不含对照学院。
- 根因：批次/审计使用 `access_service.visible_organization_ids`（只展开最具体组织根）；规范创建使用 `policies._user_scope_ids`，把用户 context 里的 `school_id` 也展开成全部下级学院。
- 影响：学院管理员可越权维护兄弟学院规范，但还不能看到或操作兄弟学院批次。
- 证据文件：[缺陷_BUG-COLLEGE-SCOPE-001.md](./缺陷_BUG-COLLEGE-SCOPE-001.md)
