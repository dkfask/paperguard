## 2. CI 修复

### 最小复现

在关闭真实邮件通道的隔离环境运行：

```bash
cd backend
env PAPERGUARD_SMTP_HOST= PAPERGUARD_RESEND_API_KEY= \
  ../.venv/bin/python -m pytest \
  tests/test_onboarding_and_certification.py::test_onboarding_paths_stay_reachable_while_blocked \
  -q -p no:cacheprovider
```

原用例稳定失败：503 `EMAIL_NOT_CONFIGURED`。分类：**TEST-DEFECT / 外部依赖未隔离**，
不是应该把业务端点改成“邮件未配置也返回成功”。

修复同时纠正 `/first-login/complete` 字段：`email` / `email_code` / `new_password`。
成功分支不再仅证明“没有 403”，而是完成引导、拿新会话、检查准入状态，并验证业务访问恢复。
缺配置、发送失败分支分别断言真实错误，账号仍保持业务阻断。

提交 `3824a1b`：相关 25 项通过，本地全量 772 项通过；四组远端 workflow（CI、浏览器 E2E、
Docker staging、生产拓扑预检）均通过。该数字是 CI 修复阶段，不是本轮追加验收后的测试总数。
