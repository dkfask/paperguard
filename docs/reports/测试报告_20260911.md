# PaperGuard 架构与 UI 调整闭环测试报告 — 2026-09-11

## 1. 结论

本次方案落地后的本地闭环结论为 **PASS WITH RESIDUAL RISK**：核心业务链、请求追踪、健康探针、后台 Worker、前端生产构建和认证后的角色工作台均通过。未部署远端，未把本地结果冒充生产 UAT；生产并发、真实设备无障碍专项和多实例共享存储仍需独立环境。

## 2. 已落地调整

- 前端增加角色工作台侧栏和 `/workspace` 角色入口，按学生、教师、学院管理员、学校管理员展示工作区；详细操作页继续通过 `panel` 查询参数定位批次、审核、材料、归档、报表和消息区域，管理员新增独立 `/audit` 审计中心。
- 增加 `AsyncState`、`StatusBadge`、`DeadlineLabel`、`ReasonDialog`、`ConfirmDialog`、`DataTable`、`TaskCard`、`ReviewQueue`、`ReviewEvidence`、`StageConfigForm`、`MemberImportWizard`、`NotificationInbox` 和 `ArchiveJobStatus` 共享组件，补齐空、加载、错误、截止和状态反馈；业务变更使用结构化原因弹窗，发布、删除、恢复、升级等确认动作不再调用浏览器原生 `confirm()`。
- 顶部导航收敛为角色上下文与移动端侧栏入口，保留键盘可达的关闭、刷新和跳转控件。
- API 为所有响应增加 `X-Request-ID`；认证请求建立 `RequestContext(actor_id/role/organization_scope/request_id)`；结构化 HTTP/Worker 日志只记录关联标识与运行元数据，不记录正文、Token 或 API Key；错误提示会带回请求 ID；新增 `/api/health/live` 和 `/api/health/ready` 探针。论文图片、规范文档、过程附件、项目 DOCX 导出和检查报告读取、归档 ZIP 下载统一沿项目/提交/指导关系/组织作用域授权，不再按“教师/管理员”角色全局放行。
- 归档和项目 DOCX 导出从长任务路径移到 SQLite 持久化 `jobs` 表和独立 Worker：创建事务返回 `202 + job_id`，任务支持租约、最大重试、退避、死信/人工重试和启动恢复；新增 `/api/jobs`、`/api/jobs/{job_id}` 查询，以及项目 `/export-jobs` 查询/下载接口。导出任务冻结项目/模板版本快照，下载端点复用项目资源授权；新增 `WorkflowRepository` 和严格 `JobResponse`，核心工作流读写与任务 API 已经过 repository/contract 边界，接口不会暴露 `lease_token`、`leased_by` 等内部租约字段。旧同步 `/export` 接口保留用于兼容历史客户端。
- 既有工作流服务、归档、通知 outbox、过程材料、版本和 Worker 链路继续由后端自动化回归覆盖。
- 增加 `paperguard migrate` 数据库迁移入口，输出 `schema_migrations` 账本；重复执行不会重复应用版本。工作流审计写入独立 `audit_events` 表，启动时兼容回填历史 `workflow_records(kind=audit)`。
- 新增 `/api/audit` 审计查询边界和 `/api/audit/export` 脱敏 CSV 导出：支持资源、动作、操作者和组织过滤；统一投影工作流与规范审计，按学院管理员组织范围过滤并脱敏，不返回正文、附件或内部租约字段。工作流审计记录增加请求 ID 关联。
- 运行与数据治理页提供健康探针、持久任务列表、保留策略和一致性备份下载入口；备份接口沿用管理员权限并在响应完成后清理临时文件。
- 增加集中式工作流状态转移表，接入阶段任务、提交、过程材料、批注和归档的关键变更；非法转移失败关闭，归档 Worker 仍可按重试/恢复路径转移。

## 5. 残余风险

- `测试策略.md` 中性能轴仍需规模化数据、P95/P99 目标和独立压测环境；本地 Worker/接口通过不代表生产吞吐。
- 无障碍已完成辅助树和窄屏基线，但完整 axe、键盘焦点、对比度和真实设备专项尚未执行。
- 远端服务器未部署、未重启、未做目标环境恢复演练；多实例部署前仍需共享对象存储和正式迁移流水线。当前 jobs 迁移已具备 SQLite 版本 ledger 和独立 `migrate` CLI，但正式回滚包仍需在部署环境演练；Workflow API 仍有部分历史查询直接使用 Store，完整 repository 迁移尚未完成。
- 当前测试环境仍有 2 个上游依赖弃用警告（Starlette/httpx），不影响功能结论，但应在依赖升级窗口处理。
