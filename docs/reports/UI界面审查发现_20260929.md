## P1

### F-10 侧边栏导航静默失效，且无法自愈

**现象**
在写作页点击侧边栏「工作台」，页面毫无反应：URL 仍为 `/write/proj-30037c78611c`，内容仍是写作页。唯一痕迹是浏览器标签标题变为「角色工作台 · PaperGuard」，与实际页面不符。

**证据**

1. Console 两次同一错误（时间戳 `1790657081688` / `1790657146637`，间隔对应两次点击）：
   ```
   TypeError: Failed to fetch dynamically imported module:
     http://43.167.211.145:8080/assets/Workspace-CmasOBPq.js
       at index-CnKBjI5S.js:3:55564
   ```
2. Network：`GET /assets/DeadlineLabel-DdLFzSC7.js` → `502 Bad Gateway`，`failureReason: net::ERR_ABORTED`，耗时 5007ms（同一批嵌套依赖失败）。
3. 资产本身完好：服务器 `/var/www/paperguard/assets/` 中 `Workspace-*.js`、`DeadlineLabel-*.js` 均存在，外部直连 `200` / 145ms。属传输层抖动，非部署缺件。
4. **重试无效**：第二次点击产生第二次同样的 TypeError，浏览器缓存了失败的模块记录。整页刷新后点击「工作台」恢复正常（已验证）。

**代码根因**（`frontend/src/router.js`）

- `:34` 在 `router.beforeEach` 内即写入 `document.title`，早于路由组件解析，因此标题先变、页面后变，导航失败后标题不回滚。
- 全项目无 `router.onError()`，也无任何导航失败兜底：不弹提示、不给重试、不回滚标题。

**影响**
任意一次网络抖动（校园网、代理、CDN 超时、部署换名瞬间）都会让用户在当前会话内**永久失去侧边栏到该路由的导航能力，且零用户可见反馈**。与此前修复的三处权限死路同类，但成因在网络/路由层，API 层与 DOM 层均无法检出。

**修复方向**
- 新增 `router.onError()`，识别动态 import 失败（`TypeError: Failed to fetch dynamically imported module`）与 `NavigationDuplicated` 之外的真实失败，弹出可见错误条并提供「重试」按钮。
- 将 `document.title` 的写入从 `beforeEach` 移到 `afterEach`，避免标题与实际路由脱节。
- 失败时提示文案需区分「页面资源加载失败」与「网络异常」，并建议整页刷新作为兜底路径。

## P3

### F-02 缺失路径返回 200 HTML

nginx `location /` 的 `try_files $uri $uri/ /index.html` 使非 `/assets/` 的缺失文件返回 `200 text/html`：

```
/favicon.ico   → 200 text/html（内容为 SPA index.html）
/no-such-page  → 200 text/html（SPA 路由兜底，此项符合预期）
/assets/does-not-exist.js → 404（正确）
```

后果：缺失资源无法从状态码检出，浏览器拿到 HTML 当图片/脚本解析。

**修复方向**：为 `/assets/` 之外的静态扩展名（`.ico .png .svg .css .js .woff2` 等）加 `location` 精确匹配，命中即 `404`。

**修复方向**：部署脚本 rsync 排除 `._*` 与 `.DS_Store`。

### F-11 学生工作台「最近提交」的状态徽章无样式（结论已修正）

**初版结论有误，修正如下。**

初版依据截图判断「最近提交不显示状态徽章」。实际上 `StudentWorkspace.vue:58` **确实渲染了 `StatusBadge`**，后端 `_submission_list_view`（`backend/app/api/workflow.py:1543`）也正确返回了 `state` 字段（生产实测 `approved` / `returned`）。

真实根因：`.state-tag` 的配色规则写在 **`Workflow.vue` 的 `<style scoped>` 块**里。Vue 的 scoped 样式只对带该组件 scope id 的元素生效，而 `StudentWorkspace.vue` / `Workspace.vue` 渲染的 `.state-tag` 不带该 scope id，**因此徽章只有全局的 `display: inline-flex` 布局，没有任何底色、颜色、内边距**——渲染成一串裸文字，看上去就像「没有状态」。

**修复**：把 `.state-tag` 基础规则与各状态配色从 `Workflow.vue` 的 scoped 样式移到全局 `src/style.css`，并加注释说明不能放回 scoped。

**修复方向（已实施）**
- 为每条补状态徽章（复用既有 `StatusBadge`），并标出当前生效版本。
- 将 `.state-tag` 配色移入全局样式，避免 scoped 作用域导致徽章在其他视图失效。

#### F-14 教师界面存在必然 403 的死路按钮

#### F-15 两套师生绑定机制互相矛盾（数据一致性）

| 机制 | 存储 | 写入入口 |
|---|---|---|
| 账号级 | `users.teacher_id` | 教师在「指导学生」页批量导入学生（`db.py:722` `list_students_by_teacher` 查此列） |

### F-24【P2】API 层把字面量 `{}` 当作错误信息抛给用户

**根因**：`frontend/src/api.js` 的 `detailMessage` 对对象型 payload 直接
`JSON.stringify`。后端 500 与反向代理错误页返回的是**非 JSON 文本**，
`resp.json()` 解析失败后回退成空对象 `{}`，于是 `JSON.stringify({})` 得到
字面量 `"{}"`，被当作错误信息写进页面的 `error-banner`。

**影响面不止本页**：所有以非 JSON 返回错误响应的接口（502/504、反代错误页）
都会显示 `{}` 而不是可读文案。

**修复**（`7db0224`）：空对象/空数组判定为「没解析出错误信息」，回退到调用方
给出的 `fallback` 文案；后端确实给出的真实错误信息仍优先。

**回归测试**：新增 4 例（非 JSON 500、空 JSON、真实 detail、422 结构化校验），
变异验证确认能捕获回归。

**生产复验**：`/teacher/students` 刷新后 `{}` 横幅消失。

### F-13 重做：上一轮的修复方向本身就是错的

**发现过程**：生产复验点击侧边栏「待审核」，URL 变成
`/workflow?panel=review`，但高亮的 tab 是**「提交与归档」**，正文内容也是提交与归档。

**为什么第一版修复是错的**：第一版把 `review` 映射到 `submissions` section，
理由是「审核队列挂在 submissions 区」。但 `submissions` section 对应的 tab
就是「提交与归档」——所以 URL 写 `review`、界面却停在提交与归档，
**只是把一种错位换成了另一种**。用户想看的审核队列根本没出现。

**真实关系**：教师/学生的「待审核」tab 与 `overview` 共用同一个 section，
两者的 tab key 都是 `'overview'`；审核队列正渲染在 `overview` 区。
即 **section 与 tab 并非一一对应**，这正是不能复用 `activeSection` 做高亮的原因。

**重做内容**（`d2a1544`）：

1. `activeSection` 不再为 `review` 特殊处理，落回 `overview`
2. 新增 `activeTabKey`，按 URL 语义单独算出应高亮的 tab
3. tab 高亮条件由 `activeSection === tab.section` 改为 `activeTabKey === tab.key`
4. `review` 入口的 kicker/title 改为审核语义（「待审核」/「审核台」）

**顺带修掉一个假绿用例**：原用例断言「文件里出现过 `panelTarget.value === 'review'`」，
重做后该字符串出现在标题文案分支里，用例名不副实、约束不到真正的不变量。
改为断言 `activeSection` 函数体内不存在 review 映射（注释除外）、
模板高亮条件已改为 tab key、review 标题为审核语义。

**生产复验**：`panel=review` 下「待审核」tab 带 `active` + `aria-current="page"`，
标题为「审核台」。**但正文第一屏仍是「新建批次」表单**——见下。
