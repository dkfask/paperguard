# PaperGuard 全页面原型（视觉稿存档）

> 存档日期：2026-10-09 ｜ 对应构件：`PaperGuard 全页面预览`（Muse artifact `paperguard`）
> 用户已于 2026-10-08 确认当前 UI"没有什么大问题"

## 这是什么

`paperguard.html` 是 PaperGuard 三端（学生 / 教师 / 管理）共 18 个页面的**静态视觉稿**，
由构件系统导出为单文件 HTML（资源已内联），双击用浏览器打开即可浏览，无需构建。

覆盖页面：
- 学生端：任务中心、段落约束写作、AI 辅助、预检提交、批注反馈、归档下载
- 教师端：待办审核、审阅批注、材料审核、指导学生
- 管理端：批次阶段、模板规范、组织成员、归档中心、平台设置

支持角色切换、总览导航、关键弹窗与移动端重排。

## 不是什么

- **不是可运行的前端代码**：全部为演示数据，不连接任何后端接口，不持久化数据。
- **不是最终实现标准**：真实前端以仓库 `frontend/` 的 Vue 实现为准；
  本稿只锁定页面结构、信息架构与视觉语言，供开发对照。
- 与线上部署无关。

## 维护约定

- 视觉稿有实质性变更时，重新从构件导出并覆盖本文件，commit 信息注明对应的构件版本/日期。
- 不要手改这个 HTML 文件——改动统一在构件里做，再重新导出。
